# DevOps & Cloud Tools

> Tools for building, deploying, and managing modern applications and infrastructure.

## 🐳 Containerization & Orchestration

- [Docker](https://www.docker.com/) - The industry standard for building, sharing, and running containerized applications. (🐧 Open Source | 🏠 Self-Hosted)
- [Kubernetes](https://kubernetes.io/) - Production-grade container orchestration. (🐧 Open Source | 🏠 Self-Hosted)
- [Podman](https://podman.io/) - A daemonless, open source, Linux native tool for working with OCI containers and pods. (🐧 Open Source | 🏠 Self-Hosted)
- [k3s](https://k3s.io/) - Lightweight Kubernetes. Easy to install, binary is less than 100MB. (🐧 Open Source | 🏠 Self-Hosted)

## 🚀 CI/CD (Continuous Integration / Continuous Deployment)

- [GitHub Actions](https://github.com/features/actions) - Automate your workflow from idea to production within GitHub. (🌗 Freemium | ☁️ SaaS)
- [GitLab CI](https://docs.gitlab.com/ee/ci/) - Integrated CI/CD pipelines within GitLab. (🐧 Open Source | 🏠 Self-Hosted)
- [Jenkins](https://www.jenkins.io/) - The leading open source automation server. (🐧 Open Source | 🏠 Self-Hosted)
- [CircleCI](https://circleci.com/) - Continuous integration and delivery platform for fast, confident software delivery. (🌗 Freemium | ☁️ SaaS)
- [Argo CD](https://argo-cd.readthedocs.io/en/stable/) - Declarative, GitOps continuous delivery tool for Kubernetes. (🐧 Open Source | 🏠 Self-Hosted)

## 🏗️ Infrastructure as Code (IaC)

- [Terraform](https://www.terraform.io/) - Infrastructure automation to provision and manage any cloud, infrastructure, or service. (🐧 Open Source | 🏠 Self-Hosted)
- [Ansible](https://www.ansible.com/) - Simple, powerful, and agentless IT automation. (🐧 Open Source | 🏠 Self-Hosted)
- [Pulumi](https://www.pulumi.com/) - Universal Infrastructure as Code using general purpose programming languages. (🐧 Open Source | 🏠 Self-Hosted)

## 🕸️ Networking & Proxies

- [Nginx](https://www.nginx.com/) - High performance load balancer, web server, and reverse proxy. (🐧 Open Source | 🏠 Self-Hosted)
- [Traefik](https://traefik.io/) - The Cloud Native Application Proxy. (🐧 Open Source | 🏠 Self-Hosted)
- [Caddy](https://caddyserver.com/) - Powerful, enterprise-ready, open source web server with automatic HTTPS. (🐧 Open Source | 🏠 Self-Hosted)

## 🛡️ Secret Management

- [HashiCorp Vault](https://www.vaultproject.io/) - Manage secrets and protect sensitive data. (🐧 Open Source | 🏠 Self-Hosted)
- [Infisical](https://infisical.com/) - Open source secret management platform. (🐧 Open Source | 🏠 Self-Hosted)

## 🧪 Testing & QA

- [Agent QA](https://github.com/vostride/agent-qa) - Source-available CLI and MCP server for natural-language web and mobile regression tests with run memory; model-provider costs may apply. (🏠 Self-Hosted)
